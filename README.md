# digital-generation-mobile-behavior
# 消費行為與數據洞察：未成年與成年族群手機行為分析

本專案為課程專題報告《解構數位世代：未成年與成年族群手機行為深度解析》，沿用先前大一統計學自主學習報告所蒐集之問卷資料，比較未成年與成年族群在手機使用時長、付費意願與消費類型上的差異，並轉化為視覺化圖表與簡報呈現。

## 1. 研究問題與分析背景
隨著智慧型手機深入日常生活，不同年齡世代在內容消費與數位付費上的行為可能存在顯著差異。本專題希望透過數據檢定與視覺化呈現，釐清未成年與成年族群在手機使用時長、付費習慣與消費類別上的異同，作為理解數位世代消費行為的參考。

## 2. 與「行銷與數位分析」的關聯
- **族群區隔與付費行為洞察**：觀察不同年齡層在付費比例與消費類型上的差異（例如未成年較集中在遊戲與串流平台，成年人則涵蓋單一購物與長期訂閱制），有助於理解目標客群的變現與留存邏輯。
- **數據轉譯與視覺溝通**：將統計分析結果整理為直覺的圖表與重點敘事，讓非技術背景的讀者也能快速掌握關鍵趨勢與商業／行銷意涵。
- **延伸分析方向**：專案亦反思可進一步結合多維度交叉分析與儀表板工具（如 Tableau 或 Power BI），提升資料探索與決策呈現的效率。

## 3. 使用工具與資料脈絡
- **資料來源與沿用**：沿用大一統計學自主學習報告之問卷資料進行延伸分析與報告呈現。
- **分析與視覺化工具**：團隊於分析與資料整理階段運用 R 語言統計檢定、SQL 查詢與資料整理；我主要負責 **Canva 圖表製作**與**報告／簡報撰寫**，將分析結果轉化為視覺圖表與完整敘事。
